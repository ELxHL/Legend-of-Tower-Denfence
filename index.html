GitHub Repository

PUBLIC REPO

Nên giữ Pages trên main và để AI làm việc trên ai-work. Repository Free cần công khai để sử dụng GitHub Pages theo gói Free. Tài liệu GitHub Pages.

Cloudflare Worker

BACKEND BRIDGE
Admin token chỉ giữ trong session của tab hiện tại, không lưu vào localStorage. GitHub token phải là Cloudflare Secret tên GITHUB_TOKEN, không dán vào website.

Quyền GitHub cần thiết

LEAST PRIVILEGE

Backend cần Fine-grained Personal Access Token chỉ cấp cho đúng một repository, với Repository permissions: Contents – Read and write. Không cấp quyền Workflows nếu không cần. Token được lưu bằng Secret trong Cloudflare Worker.
